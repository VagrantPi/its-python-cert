## 領域 1：資料型別與運算子

**Q184.** 執行下列程式，輸出為何？
```python
a = [1, 2, 3]
b = a
c = a[:]
b.append(4)
print(a is b, a is c, a == c)
```
- A) `True True True`
- B) `True False False`
- C) `True False True`
- D) `False False True`

> **答案：B**　b = a 讓 b 和 a 指向同一個 list，所以 a is b 為 True，b.append(4) 也改到 a；c = a[:] 是另一份複本，a is c 為 False，且 a 已變成 [1, 2, 3, 4]、c 仍是 [1, 2, 3]，所以 a == c 也是 False。選 C 的人忽略了 append 會影響 a。

**Q185.** 已知 d = {"a": 1, "b": 2}，下列哪些運算式的結果為 True？（複選）
- A) `"a" in d`
- B) `1 in d`
- C) `2 in d.values()`
- D) `("a", 2) in d.items()`

> **答案：A, C**　對 dict 使用 in 只會檢查「鍵（key）」："a" 是鍵所以 A 為 True，1 是值不是鍵所以 B 為 False。要檢查值須用 d.values()，C 為 True。d.items() 裡是 ("a", 1)，沒有 ("a", 2)，D 為 False。

**Q186.** 執行下列程式，輸出為何？
```python
x = 5
print(x > 3 or x < 0 and not x == 5, not x > 3 or x < 0)
```
- A) `False False`
- B) `True True`
- C) `False True`
- D) `True False`

> **答案：D**　優先順序是 not > and > or，比較運算子又比 not 先算。第一個運算式先算 x < 0 and not x == 5 得 False，再算 True or False 得 True（若由左往右算 (True or False) and False 會誤得 False）。第二個是 (not True) or False，結果 False。

**Q187.** 執行下列程式，輸出為何？
```python

print(1 < x < 5, 3 > 2 > 1 == 1, 5 > x > 4)
```
- A) `True False False`
- B) `False True False`
- C) `True True False`
- D) `True False True`

> **答案：C**　連鎖比較 a < b < c 等於 a < b and b < c。3 > 2 > 1 == 1 是 3 > 2 and 2 > 1 and 1 == 1，三者都成立為 True（不是先算 3 > 2 得 True 再和 1 比）。5 > x > 4 中 3 > 4 不成立，為 False。

**Q190.** 執行下列程式，輸出為何？
```python

```
- A) `-3 -1`
- B) `-3 2`
- C) `-4 -1`

**Q196.** 執行下列程式，輸出為何？
```python
x = 5
y = -2
if x > 0:
    if y > 0:
        print("甲")
else:
    print("乙")
print("丙")
```
- A) `甲 與 丙`
- B) `乙 與 丙`
- C) `只有 丙`
- D) `只有 乙`

> **答案：C**　else 和外層的 if x > 0 對齊，所以它屬於外層。x > 0 成立，進入外層；內層 y > 0 不成立且內層沒有 else，什麼都不印。外層已成立，所以外層的 else 也不執行，最後只印出「丙」。選 B 的人把 else 誤當成內層 if 的 else。

**Q265.** 執行結果為何？
