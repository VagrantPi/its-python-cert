## 一、字串格式化（5 題）

**Q1.**
```python
price = 3.14159
print("{:.2f}".format(price))
```
輸出為何？
- A) `3.14`
- B) `3.142`
- C) `3.1`
- D) `3.14159`

**Q2.**
```python
print("{1}-{0}-{1}".format("A", "B"))
```
輸出為何？
- A) `A-B-A`
- B) `B-A-B`
- C) `A-B-B`
- D) 產生 IndexError

**Q3.**
```python
name = "Bob"
print(f"[{name:>8}]")
```
輸出為何？
- A) `[Bob     ]`
- B) `[     Bob]`
- C) `[  Bob   ]`
- D) `[Bob]`

**Q4.** 要將 `total = 1234567` 印成 `1,234,567`，下列何者正確？
- A) `print("{:,}".format(total))`
- B) `print("{:,d}".format(total))`
- C) `print(f"{total:,}")`
- D) 以上皆可

**Q5.**
```python
rate = 0.2567
print("{:.1%}".format(rate))
```
輸出為何？
- A) `0.3%`
- B) `25.7%`
- C) `25.67%`
- D) `0.2567%`

### 解答

| 題號 | 答案 | 解析 |
|---|---|---|
| Q1 | **A** | `.2f` 表示固定小數點 2 位，會做四捨五入（實際為 banker's rounding，此例仍得 3.14）。 |
| Q2 | **B** | `{n}` 為位置索引，索引可重複使用、可跳號。 |
| Q3 | **B** | `>` 靠右對齊、`<` 靠左、`^` 置中；`8` 是總寬度，不足補空白。 |
| Q4 | **D** | `,` 為千分位符號，`format()`、f-string、`{:,d}` 三種寫法等效。 |
| Q5 | **B** | `%` 會先乘以 100 再加上百分號，`.1` 控制小數位數。 |

## 二、開檔與讀檔（5 題）

**Q6.** `data.txt` 原本已有內容，執行下列程式後，檔案內容為何？
```python
f = open("data.txt", "w")
f.write("Hello")
f.close()
```
- A) 原內容 + `Hello`
- B) 只剩 `Hello`（原內容被清除）
- C) 拋出 FileExistsError
- D) `Hello` + 原內容

**Q7.** `a.txt` 內含三行文字。下列 `data` 的型別與長度為何？
```python
with open("a.txt") as f:
    data = f.readlines()
```
- A) str，長度為總字元數
- B) list，長度 3
- C) tuple，長度 3
- D) 產生錯誤

**Q8.** 使用 `with open(...) as f:` 的主要好處為何？
- A) 讀取速度較快
- B) 可同時開啟多個檔案
- C) 區塊結束時（含發生例外）會自動關閉檔案
- D) 自動將檔案內容轉為 list

**Q9.**
```python
with open("a.txt") as f:
    for line in f:
        print(line)
```
輸出每行之間多出空白行，原因與修正方式為何？
- A) `print` 的 bug，改用 `sys.stdout.write`
- B) `line` 本身含換行字元，可改為 `print(line, end="")` 或 `print(line.strip())`
- C) 檔案編碼錯誤，需指定 `encoding="utf-8"`
- D) 需改用 `f.readlines()`

**Q10.** 以 `"a"` 模式開啟檔案時，下列敘述何者正確？
- A) 檔案不存在會拋出 FileNotFoundError
- B) 寫入位置在檔案開頭，會覆蓋原內容
- C) 檔案不存在會自動建立，寫入位置在檔尾
- D) 只能讀取，不能寫入

### 解答

| 題號 | 答案 | 解析 |
|---|---|---|
| Q6 | **B** | `w` 模式會清空（truncate）既有內容；要保留請用 `a`。 |
| Q7 | **B** | `readlines()` 回傳 list，每個元素是一行（含 `\n`）；`read()` 才回傳單一 str。 |
| Q8 | **C** | context manager 保證離開區塊時呼叫 `close()`，例外發生時也會釋放資源。 |
| Q9 | **B** | 逐行迭代得到的字串尾端保留 `\n`，`print` 再補一個換行。 |
| Q10 | **C** | `a` = append，檔案不存在則建立，指標固定在檔尾。`r` 模式檔案不存在才會 FileNotFoundError。 |

### 開檔模式對照表

| 模式 | 檔案不存在 | 既有內容 | 可讀 | 可寫 |
|---|---|---|---|---|
| `r` | 錯誤 | 保留 | ✓ | ✗ |
| `w` | 建立 | 清空 | ✗ | ✓ |
| `a` | 建立 | 保留 | ✗ | ✓（檔尾）|
| `x` | 建立 | — | ✗ | ✓ |
| `r+` | 錯誤 | 保留 | ✓ | ✓ |

## 三、try / except 例外處理（5 題）

**Q11.**
```python
try:
    result = 10 / 0
except ZeroDivisionError:
    print("A")
except Exception:
    print("B")
else:
    print("C")
finally:
    print("D")
```
輸出順序為何？
- A) `A` `D`
- B) `A` `C` `D`
- C) `B` `D`
- D) `A` `B` `D`

**Q12.**
```python
lst = [1, 2, 3]
try:
    print(lst[5])
except ValueError:
    print("V")
except IndexError:
    print("I")
except Exception:
    print("E")
```
輸出為何？
- A) `V`
- B) `I`
- C) `E`
- D) 程式中斷並顯示 traceback

**Q13.** 下列程式為何無法如預期捕捉 `ValueError` 並印出 `V`？
```python
try:
    n = int("abc")
except Exception:
    print("E")
except ValueError:
    print("V")
```
- A) `int()` 不會拋出 ValueError
- B) `Exception` 是父類別，會先攔截所有例外，具體例外應寫在前面
- C) 一個 try 只能有一個 except
- D) 需要加上 `finally` 才會生效

**Q14.**
```python
def test():
    try:
        return "A"
    finally:
        print("B")

print(test())
```
輸出為何？
- A) `A` 然後 `B`
- B) `B` 然後 `A`
- C) 只有 `A`
- D) 只有 `B`

**Q15.** 要一次捕捉 `ValueError` 與 `TypeError`，並取得例外訊息，正確寫法為何？
- A) `except ValueError, TypeError as e:`
- B) `except (ValueError, TypeError) as e:`
- C) `except ValueError or TypeError as e:`
- D) `except [ValueError, TypeError] as e:`

### 解答

| 題號 | 答案 | 解析 |
|---|---|---|
| Q11 | **A** | 例外被 `ZeroDivisionError` 攔下 → 印 `A`；`else` 只在「try 區塊沒有例外」時執行，故跳過 `C`；`finally` 無論如何都執行 → `D`。 |
| Q12 | **B** | 索引超出範圍為 `IndexError`；except 由上往下比對，第一個相符者執行後即離開。 |
| Q13 | **B** | `ValueError` 是 `Exception` 的子類別，被前面的 `except Exception` 先攔截，後面的分支永遠不會執行（順序應由具體到一般）。 |
| Q14 | **B** | `finally` 在函式 `return` 之前執行，因此先印 `B`，函式回傳後才由外層 `print` 印出 `A`。 |
| Q15 | **B** | 多重例外須用 tuple 包起來；`as e` 綁定例外物件，可用 `str(e)` 取得訊息。 |

## 考前重點提醒

- **格式化**：`{:[填充][對齊][寬度][,][.精度][型別]}`，型別常考 `f` / `d` / `%` / `s`。
- **檔案**：優先使用 `with`，並記熟模式表；`read()` → str、`readline()` → 單行 str、`readlines()` → list。
- **例外**：except 順序「具體 → 一般」，`else`（無例外才跑）與 `finally`（一定跑）的差別是高頻考點。
